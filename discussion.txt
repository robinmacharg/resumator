ARCHITECTURE & TASK BRIEF

Goal
Build a local CV projection pipeline centered on generate_cv.py and research_role.py with a clear file contract:

- Input files live under input/
- Generated artifacts live under output/

Core flow

- Read input/CV.md (master record) and input/jobspec.txt (target description).
- Build a prompt from input/prompt.md and invoke the selected model provider.
- Write generated CV artifacts to output/.
- Convert output/tailored.md into output/tailored_dev.pdf and output/tailored_dev.docx.

Input file contract

- input/CV.md: master career database
- input/jobspec.txt: role requirements
- input/prompt.md: tailoring prompt template
- input/research_prompt.md: research prompt template
- input/research_prompt.default.md: default research prompt template
- input/research_company.txt: persisted company name
- input/research_urls.txt: persisted URL list

Output file contract

- output/tailored.md
- output/tailored.model-output.txt
- output/tailored.model.json
- output/tailored.export.md
- output/tailored_dev.pdf
- output/tailored_dev.docx
- output/research_output.md
- output/research_output.json
- output/research_prompt.built.txt
- output/research_output.formatted.md
- output/research_output.formatted.pdf
- output/gemini_debug_logs/*.log

High-level diagram

[ input/CV.md ] + [ input/jobspec.txt ] + [ input/prompt.md ] -> model provider -> [ output/tailored.md ] -> converter -> [ output/tailored_dev.pdf | output/tailored_dev.docx ]

Research flow

[ input/research_prompt.md ] + [ input/research_company.txt ] + [ input/research_urls.txt ] + [ input/CV.md ] + [ input/jobspec.txt ] -> model provider -> [ output/research_output.md + output/research_output.json ] -> formatter -> [ output/research_output.formatted.pdf ]

Execution workflow

1. Ensure required inputs exist in input/.
2. Ensure .env is configured (provider keys/options).
3. Run CV pipeline:
   python3 generate_cv.py
4. Run research pipeline:
   python3 research_role.py --company-name "Your Company"
5. Optional formatting step:
   python3 research_format.py

Web wrapper behavior

- The web server reads and writes editable files from input/.
- Generated previews and downloads resolve from output/.
- Run logs are indexed from output/gemini_debug_logs/.

Notes

- output/ is considered generated content and is ignored by git.
- .env remains at project root by design.
